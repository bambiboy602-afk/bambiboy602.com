## Conversational Specification & Problem Mapping Engine

#### Layer 2: Recursive Mapping Engine (RSM)
Every problem is mapped through scales:
```
        Center (What hurts?)
         ↑                  ↓

   (Expansion)            (Reduction)
```

##### Expansion Example (Relapse):

### The 5 Recurring Boundary Failures

Every human mental-health struggle collapses into one of five recurring boundary failures:

#### 1. Relief Failures
- **Pattern**: `Pain → Relief`
- **Examples**: Addiction, self-harm, compulsive behavior.
- **Root Failure**: The person has only one reliable relief pathway.
- **Intervention**: Increase alternative relief pathways. Smallest useful change: delay 15 minutes, leave environment, call sponsor.

#### 2. Meaning Failures
- **Pattern**: `Event → Interpretation`
- **Examples**: Trauma, shame, grief.
- **Root Failure**: The event ended, but the interpretation remains active in the nervous system.
- **Intervention**: Reality-test interpretation, grounding, separate event from permanent meaning.

#### 3. Prediction Failures
- **Pattern**: `Unknown → Future Catastrophe`
- **Examples**: Anxiety, obsession, panic.
- **Root Failure**: The nervous system predicts catastrophic outcomes for any unresolved uncertainty.
- **Intervention**: Increase uncertainty tolerance, box breathing, sensory reorientation.

#### 4. Connection Failures
- **Pattern**: `Need → Disconnection / Isolation`
- **Examples**: Loneliness, attachment issues, abandonment fears.
- **Root Failure**: Need exists, but connection pathway is broken or defended.
- **Intervention**: Repair connection pathways through small, safe micro-interactions.

#### 5. Identity Failures
- **Pattern**: `Action / Mistake → Self-Definition`
- **Examples**: Shame, personality collapse, existential crises.
- **Root Failure**: The person mistakes temporary behavior for permanent identity.
- **Intervention**: Separate action from self-definition: *"Failure is an event, not your identity."*

### Layer 3: Tom (The Conversational Guide)
The user only experiences Tom; Tom secretly runs RSM.

```
User
  ↓
Tom (Conversation Layer)
  ↓
RSM (Analysis Layer)
  ↓
Boundary Detection
  ↓
Intervention Selection
  ↓
Stabilization Tracking
```

#### Runtime Loop:
1. **Observe**: Gather information without interpretation (*What happened? When? What led up to it?*).
2. **Locate**: Identify the single active problem center point (not twenty).
3. **Reduce**: Ask: *What is this made of?*
4. **Expand**: Ask: *What does this affect?*
5. **Boundary Analysis**: Determine failure category (Relief, Meaning, Prediction, Connection, Identity).
6. **Intervention**: What is the smallest useful change? (Change one link, don't fix life).
7. **Stabilization**: *Can this repeat?* If yes, reinforce. If not, select new micro-intervention.

#### Conversation Rules:
- **Avoid**: *"You should"*, *"You need to"*, *"You must"*.
- **Prefer**: *"What do you think would happen if..."*, *"Have you noticed..."*, *"When did that begin..."*.
- **Crisis Mode**: Suicidal intent, homicide intent, inability to remain safe, medical emergency → Normal RSM pauses; human safety and 988 emergency protocols become priority.
- **Recovery Mode Goal**: Increase stability, not force immediate elimination of all symptoms.
